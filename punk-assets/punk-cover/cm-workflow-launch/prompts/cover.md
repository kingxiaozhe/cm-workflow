# 黑红剪影公众号封面提示词

你是一位顶级封面艺术指导、编辑视觉设计师、字体设计师和图像生成提示词导演。

请创作一张单幅微信公众号文章封面，画幅比例严格为 2.35:1。用途是公众号长文首图，在手机信息流中必须一眼可辨。

本封面只使用「黑红剪影 / black-red-silhouette」一种视觉风格。它不是后期滤镜，而是整张封面的构图、主体、文字、空间和隐喻共同遵守的视觉语言。

## 输入与文字层级

- 主题：AI 宣称“已经完成”，但开发任务可能没有经过真实测试与验证。
- A 层主标题，必须逐字准确：`AI 真的完成了吗？`
- B 层副标题，必须逐字准确：`没有证据，就不能说完成`
- C 层小标签，必须逐字准确：`CM WORKFLOW`
- 平台：微信公众号
- 画幅比例：2.35:1 横版
- 语言：中文为主，少量英文
- 受众：使用 Codex、Claude Code 等 AI 编程工具的开发者、一人公司和中小研发团队
- 情绪：冷峻、紧张、克制、清醒、有秩序

## 内容理解与封面目标

文章讲述作者多次被 AI 的“已经完成”误导：正式测试没有真正运行、页面关键路径没有走完、聊天总结缺少可审查证据。作者最终把规格确认、任务串行执行、独立审查、真实测试和证据留存整理为 CM Workflow。

封面第一眼必须让读者看到“AI 真的完成了吗？”，第二眼通过断桥隐喻意识到：一个醒目的完成勾并不代表交付链路真的闭合。画面要像成熟的编辑封面，不像课程封面、PPT、广告或信息图。

## 黑红剪影风格落地

严格只使用纯红、纯黑、白色三种颜色：

- 大面积纯红色平面背景，占画面绝大多数面积；无渐变、无纹理、无颗粒。
- 黑色负责主体、断桥和几何剪影，形成最大视觉重量。
- 白色只用于主标题、副标题、小标签、巨大完成勾和极少量高光。
- 所有形状扁平、轮廓清晰、干净利落，像红色舞台上的黑色动画剪影。
- 禁止真实摄影感，禁止人物五官，禁止复杂 UI，禁止多场景叙事。

## 构图

采用横向 2.35:1 编辑封面构图。

- 主视觉位于画面中心偏右和下方：一名手持笔记本电脑的黑色开发者剪影，站在一座黑色桥面的断口前，身体微微前倾但及时停住。
- 桥面从右下方延伸到画面中心，在人物前方明确缺少一段，形成干净、易懂的断桥轮廓；不要画成深渊恐怖场景。
- 断桥上方悬着一个巨大、简洁、白色的完成勾。它看起来非常肯定，但与下方未接通的桥形成直接矛盾。
- 不加入锁链、机械流水线、大手、机器人、人脸、代码雨、图表或界面面板。
- 主标题位于画面左侧安全区，纵向居中偏上，与右侧剪影保持充足留白。
- 副标题紧随主标题下方，字号明显更小。
- `CM WORKFLOW` 作为极小编辑标签放在左上或左下安全区，不增加其他文字。
- 阅读顺序：左侧主标题 → 右侧巨大完成勾 → 下方断桥与人物 → 左侧副标题。
- 所有重要内容距离四周边缘保留安全区，不得裁切标题、完成勾、人物或断桥。

## 图文关系与字体

文字必须融入红色舞台空间，不能像后来贴上去的说明文字。

- 主标题使用白色现代粗黑体或几何黑体，清楚、有力量、不过度膨胀。
- 主标题分成自然的两行，但必须完整显示 `AI 真的完成了吗？`，不得错字、漏字、改字。
- 副标题使用白色或暖白色中等字重，完整显示 `没有证据，就不能说完成`。
- 英文标签使用窄体无衬线大写，完整显示 `CM WORKFLOW`。
- 除上述三组文字外，画面中不得出现任何其他文字、随机字符或伪代码。
- 文字是辅助信息，第一视觉仍然是巨大完成勾与断桥前的人物剪影。

## 色彩、材质与质感

保持完全扁平、干净的色块语言。红色背景均匀纯净，黑色剪影边缘锐利，白色标题和完成勾对比强烈。不要阴影、霓虹、光晕、金属、玻璃、3D、纸张、做旧、磨损、颗粒或脏污质感。

## 禁止项

禁止蓝色、紫色、绿色、棕色、灰脏色、金属色及任何第四种颜色；禁止渐变、复杂光效、赛博蓝光、真实摄影、人脸细节、复杂背景、信息图、多栏布局、课程封面感、电商广告感、PPT 模板感、机器人俗套形象、密集代码、无关装饰、文字成为唯一主视觉。

禁止标题错字、漏字、乱码、被遮挡、被裁切或严重变形。禁止复制文章长正文到图片中。

## 最终标准

只生成一张最终封面，不要输出解释、备选方案、拼图、网格、联系表或多版本排版。最终画面必须是 2.35:1 微信公众号横版封面；主题一眼可辨；断桥与完成勾的隐喻清晰；严格保持红黑白三色黑红剪影风格；主标题、副标题和英文标签准确可读。
