# B 方案：复古大字报公众号封面

Use case: ads-marketing
Asset type: 微信公众号文章横版封面
Input image: 用户提供的第二张图片只作为视觉气质参考；学习其米白纸面、黑红巨型中文标题、中央产品装置、右侧规则卡片和编辑式宣传层级，不复制原图手机内容、数据、文案、印章或具体布局。

你是一位顶级中文宣传海报艺术指导、商业科技杂志设计师和公众号封面设计师。生成一张原创微信公众号文章封面，严格使用 2.35:1 横向画幅。

封面只采用「商业杂志头版 / business-magazine-front-page」这一种 Punk 风格。整体具有中文复古大字报的冲击力，同时保持可信、成熟，不做廉价财经模板。

## 内容与文字

- A 层主标题，必须逐字准确：`AI 真的完成了吗？`
- B 层副标题，必须逐字准确：`没有证据，就不能说完成`
- 顶部红色短结论，必须逐字准确：`别只看 AI 总结`
- 四张规则卡片，必须分别逐字准确：`先写规格`、`真实测试`、`独立审查`、`留下证据`
- 底部品牌标签，必须逐字准确：`CM WORKFLOW · CREATE MORE`
- 除上述文字外，不出现任何随机文字、假数据、阅读量、网址、伪代码、媒体刊名或品牌标志。

文章核心：AI 可以很快写代码，但它说“已经完成”并不等于正式测试运行过、页面关键路径验证过或独立审查通过。CM Workflow 用规格、测试、审查与证据，让每一次完成都可检查。

## 商业隐喻与主视觉

只使用一个商业隐喻：一台略微倾斜的黑色笔记本电脑或终端屏幕，立在简洁圆形展台上，屏幕中只有一个巨大勾选框和一条明显未完成的断裂进度线。它代表“表面打勾，但交付链路没有闭合”。

终端不显示真实产品界面，不出现小字列表，不伪造软件截图。主视觉应像杂志头版中的产品装置，而不是电商产品广告。

## 构图

- 左侧约 43%：超大中文主标题，三行以内，黑色为主，“真的完成”使用克制正红色。标题是第一视觉，字形粗重清晰。
- 主标题下方：副标题使用较小黑字，配一条细黑编辑线。
- 中间约 27%：倾斜终端屏幕与圆形展台，屏幕上的勾选框和断裂进度线清楚可见。
- 右侧约 28%：顶部一条红色刷痕标题条写“别只看 AI 总结”；下方四张米白描边规则卡片以 2×2 排列，分别写“先写规格”“真实测试”“独立审查”“留下证据”。
- 底部横向黑色刷痕或编辑条写 `CM WORKFLOW · CREATE MORE`，保持克制，不遮挡主体。
- 使用少量红色箭头、细线和编辑标记连接标题、终端与规则卡片，但不做复杂流程图。
- 所有文字必须有安全边距，公众号缩略图中主标题仍然完整清晰。

## 色彩、字体与材质

- 背景为温暖米白、浅旧纸色，允许轻微均匀纸张质感，但不要脏污和严重做旧。
- 主色只用深黑、正红、米白，允许极少量浅金作为卡片细边，不加入蓝绿紫。
- 中文标题使用粗重、紧凑、具有印刷大字报力量感的黑体；字形必须标准、清晰、准确。
- 红色只用于标题重点、短结论条、箭头和极少强调，面积受控。
- 形成商业科技杂志头版的权威层级，但不得出现真实刊头、媒体 Logo 或商标。

## 禁止项

不要复制参考图的真实手机画面、账号内容、阅读数据、点赞数据、印章、箭头位置或原文案；不要伪造指标；不要信息塞满；不要股票屏、握手人物、无关商务人士、廉价金融模板、复杂 UI、真实品牌、二维码、网址、水印、课程封面感或电商促销角标。

只生成一张完整封面，不要输出说明、备选、网格或联系表。
