# A 方案：手绘知识笔记公众号封面

Use case: ads-marketing
Asset type: 微信公众号文章横版封面
Input image: 用户提供的第一张图片只作为视觉气质参考；学习其白底手绘、粗笔标题、简单角色和少量批注的表达方式，不复制原图人物、构图、文案或具体图形。

你是一位顶级公众号封面艺术指导、手绘编辑插画师和中文字体设计师。生成一张原创的微信公众号文章封面，严格使用 2.35:1 横向画幅。

封面只采用「法式极简墨线海报 / french-minimal-ink-poster」这一种 Punk 风格。画面应像作者亲手画出的知识笔记：温暖象牙白纸面、黑色粗记号笔和墨线、轻微不规则手工边缘、大片留白，以及不超过画面 3% 的暗红色批注。不要混入其他风格。

## 内容与文字

- A 层主标题，必须逐字准确：`AI 真的完成了吗？`
- B 层副标题，必须逐字准确：`没有证据，就不能说完成`
- C 层小标签，必须逐字准确：`CM WORKFLOW · 01`
- 可选红色手写批注，必须逐字准确：`先验证`
- 除上述文字外，不出现其他文字、随机字母、伪代码、网址或签名。

文章讲述作者多次被 AI 的“已经完成”误导：测试没有真正运行、关键页面路径没有走完、聊天总结没有证据。作者最终建立 CM Workflow，用规格、测试、独立审查和证据约束 AI 开发。

## 核心隐喻

只使用一个隐喻：一只大号手绘对话气泡代表 AI 的“已完成”结论，但气泡底部出现一道明显裂口；一个圆润、原创、无品牌特征的黑色小角色，手持放大镜蹲在裂口旁认真检查。裂口边缘有极少量方形像素点，让科技联想清楚但克制。

不要照抄参考图中的黑色角色外形、尺子、剪刀、三张英文纸片或原构图。设计一个新的小角色姿态和新的裂口结构，保持原创。

## 构图

- 左侧约 44% 是手绘隐喻场景：大号对话气泡、裂口、检查裂口的小角色。
- 右侧约 50% 是标题区，保留宽松留白。
- 主标题使用有手写感但高度可读的中文粗黑字，分成两行或三行；不得错字、漏字、断字或裁切。
- 副标题位于主标题下方，字号明显更小，使用清晰的手写黑体。
- 用一条暗红色手绘下划线强调主标题中的“真的完成”；红色手写批注“先验证”用细箭头指向气泡裂口。
- `CM WORKFLOW · 01` 作为小型编辑标签放在右下方安全区。
- 所有重要文字距离边缘留出安全区，在手机信息流缩略图中仍然清楚。

## 视觉语言

- 背景为干净温暖的象牙白或极浅旧纸色，70% 以上保持呼吸感。
- 黑色线条粗细不均，有自然停顿、断裂、轻微毛边和墨水手感，但整体清爽。
- 只允许一种强调色：暗红。暗红只用于下划线、批注箭头和一个小节点。
- 不使用蓝色、橙色、绿色或其他颜色。
- 科技痕迹只通过气泡裂口处少量方形像素表达，不出现机器人、芯片、电路板、代码雨、复杂 UI 或数据面板。

## 禁止项

不要复制参考图的具体人物、物件、文字或版式；不要真实摄影、3D、商业科技落地页、信息图、图标堆叠、多重隐喻、复杂场景、大片色块、过多文字、课程封面感、电商广告感、水印、日期、网址和无关品牌。

只生成一张完整封面，不要输出说明、备选、网格或联系表。
