# 资金费率异常提醒工具 —— PRD

> 成熟度：**L1 半成品骨架** ｜ 类型：B 开发者工具 / 脚本 ｜ 领域包：trading（已加载）

## 问题陈述
做期现套利/持有永续仓位时，资金费率转负或异常飙高意味着"利息"变"亏损"或出现入场机会，
但人不可能 7×24 盯每 8 小时一次的结算。错过转负 = 白亏几期费率。

## 核心方案
一个自用 Python 脚本（服务器常驻），轮询币安全部 USDT 永续的预测/实时资金费率，
命中规则时通过 Server酱 推送到微信。**只读行情、不碰账户、不下单。**

## 目标用户
自己（单用户自用，无账户体系）。

## 用户故事（标题级）
1. 持仓币种费率**转负**时，8 小时结算前收到微信提醒
2. 任意币种费率**异常飙高**（>0.10%/8h）时收到"机会提醒"
3. 同一异常**不重复轰炸**（同币同状态 24h 内只推一次）
4. 每天早上收到一条**费率 TOP5 日报**（可关）
5. 脚本挂了或 API 连续失败时，收到**存活告警**（防"静默失联以为天下太平"）

## 触发规则（首版，可调参数）
- 转负提醒：预测费率 < 0 且我在自选清单里标了"持仓"
- 机会提醒：预测费率 > +0.10%/8h（全市场扫描）
- 去重：同币种同规则 24h 冷却；日报每天 09:00 一条

## 成功指标（含领域包强制的风险口径）
- 持仓币转负的提醒**漏报 = 0**（核心存在性指标）
- 提醒到达延迟 < 10 分钟（费率 8h 结算，10min 足够）
- 脚本静默失联 > 30 分钟必有存活告警 —— 监控工具自己不能是黑箱

## 范围边界
- ✅ 币安 USDT 永续（单交易所起步）
- ❌ 不下单、不自动平仓、不接交易 Key（纯只读，无资金风险面）
- ❌ 不做多交易所、不做网页界面（都留到验证有用之后）

## ⚠️ 待明确的问题（领域包强制项）
- **Key 安全**：行情接口无需 Key；若日后加"我的持仓"自动识别，需只读 Key + 禁提现校验（三道闸）
- **极端行情处置**：币安 API 限频/宕机时的退避与告警策略（骨架已含存活告警，参数待定）
- **合规边界**：纯自用监控工具、不代客、不荐股 → 无监管定性问题；若日后分享给他人需重估（领域包红线）
- **阈值科学性**：+0.10%/8h 是经验值，跑两周真实数据后回看调参 ⚠️ 待补
